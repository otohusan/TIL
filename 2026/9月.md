### Screen コマンド

ターミナルのセッションを維持したまま、切断・再接続できるコマンド。
SSH 接続が切れても処理を継続したいときに便利。

```bash
# 名前を付けてセッションを開始
screen -S work

# セッションから離れる（screen 内で入力）
Ctrl-a d

# セッション一覧を表示
screen -ls

# セッションに再接続
screen -r work

# セッションを終了
screen -S work -X quit
```

### WebP

Google が開発した Web 向けの画像形式。
JPEG や PNG よりファイルサイズを小さくしやすく、Web ページの表示速度改善に役立つ。

- 非可逆圧縮と可逆圧縮の両方に対応
- 透過画像やアニメーションにも対応
- 現在は主要なブラウザで利用可能

ImageMagick を使う場合は、次のように変換できる。

```bash
# JPEG から WebP に変換
magick input.jpg output.webp

# 品質を指定して変換（0〜100）
magick input.jpg -quality 80 output.webp
```
