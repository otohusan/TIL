### Monotonic clock

- 決して戻ることがなく、一定のスピードで進む仕組み
- ベンチマークで経過時間などを図る際に向いている

### Process.clock_gettime

指定したクロックから現在時刻を取得するRubyのメソッド。処理時間の計測には、システム時刻の変更に影響されない Process::CLOCK_MONOTONIC を使う。

```ruby
start = Process.clock_gettime(Process::CLOCK_MONOTONIC)
# 何らかの処理
elapsed = Process.clock_gettime(Process::CLOCK_MONOTONIC) - start
puts elapsed # 例: 0.523（約0.523秒）
```

### DB のインデックスを貼ると

インデックスを作ると、collection 本体とは別に、B木構造のデータがストレージ上に増える

だから、ストレージのデータ量が増える

```
Collection
┌──────────────────┐
│ {_id: 1, age: 20}│
│ {_id: 2, age: 35}│
│ {_id: 3, age: 25}│
│ {_id: 4, age: 25}│
│ {_id: 5, age: 25}│
│ {_id: 6, age: 25}│
└──────────────────┘

        +

Index on age
       [25]
      /    \
   [20]    [35]
```

検索する際には、検索に向いたB木構造のデータが利用できるようになるから、早く探索を行える

書き込みなどは、通常のコレクションに加えてB木構造のデータにも追加する必要が出てくるから遅くなる場合がある
