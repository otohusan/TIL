## 8 月 4 日

### Monotonic clock

- 決して戻ることがなく、一定のスピードで進む仕組み
- ベンチマークで経過時間などを図る際に向いている

### Process.clock_gettime

指定したクロックから現在時刻を取得するRubyのメソッド。処理時間の計測には、システム時刻の変更に影響されない Process::CLOCK_MONOTONIC を使う。

```ruby
start = Process.clock_gettime(Process::CLOCK_MONOTONIC)
# 何らかの処理
elapsed = Process.clock_gettime(Process::CLOCK_MONOTONIC) - start
puts elapsed # 例: 0.523（約0.523秒）
```

## 8 月 14 日

### DB のインデックスを貼ると

インデックスを作ると、collection 本体とは別に、B木構造のデータがストレージ上に増える

だから、ストレージのデータ量が増える

```
Collection
┌──────────────────┐
│ {_id: 1, age: 20}│
│ {_id: 2, age: 35}│
│ {_id: 3, age: 25}│
│ {_id: 4, age: 25}│
│ {_id: 5, age: 25}│
│ {_id: 6, age: 25}│
└──────────────────┘

        +

Index on age
       [25]
      /    \
   [20]    [35]
```

検索する際には、検索に向いたB木構造のデータが利用できるようになるから、早く探索を行える

書き込みなどは、通常のコレクションに加えてB木構造のデータにも追加する必要が出てくるから遅くなる場合がある

### メール1行の字数に関するRFC

メールには、**1行の長さ**に制限があるらしい

- 1行は最大998文字で、78文字以内が推奨されている
- 998文字の理由は SMTP(電子メール用のプロトコル)の制限が理由
- 78文字推奨はメールサービス側のUI上での不審然な折り返しなどが行われないためらしい

余談

- rails の Premailer（HTMLメールをテキスト化とか色々できるGem） でもデフォルトでメールの本文を折り返すけど、これは65文字になってる
  - 理由は見つけられなかった

#### 参考

- [RFC 5322 Section 2.1.1 - Line Length Limits](https://www.rfc-editor.org/rfc/rfc5322.html#section-2.1.1)
- [RFC 5321 Section 4.5.3.1.6 - Text Line](https://www.rfc-editor.org/rfc/rfc5321.html#section-4.5.3.1.6)
